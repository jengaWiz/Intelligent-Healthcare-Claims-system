# M1 local synthetic demo release

## Delivered behavior

A reviewer can sign in locally, create/upload a synthetic claim, follow durable
asynchronous processing, inspect persisted results, resolve review-required data,
and retrieve complete audit history. API/worker/database/uploads run in Docker;
queued work and accepted documents survive restart. Paired backup/restore and
retained-image redeploy were rehearsed on disposable compose projects.

The user selected **local Docker only; no hosting cost**. Public paid staging and
HTTPS provisioning are outside this release. Bind only to loopback.

## Configuration and migrations

Generate private runtime credentials with `python -m scripts.init_demo` after
locked installation; existing values are preserved. DEMO_PASSWORD and the operator
API_AUTH_TOKEN are distinct. PUBLIC_ORIGIN must match the browser origin.
SESSION_SECURE=false is for loopback HTTP only. SYNTHETIC_MODE=true avoids provider
calls and accepts only labeled sample hashes. Live mode requires separately
configured Azure and selected LLM credentials/model; they never enter frontend assets.

Required migration head is **b61ceaf00211**, including job aliases a04b9c2d310f and
browser ownership/sessions b61ceaf00211. Compose runs migration/reconciliation gates
before starting API/worker. Stop writes before changing schemas.

## Rollback and operational limits

[Deployment runbook](../deployment.md) describes private paired backups, fresh
project restore, credentials, and retained schema-compatible images. Keep the
release image ID and commit in the GitHub release. The prior integrated baseline
before this batch is 4b43a56b25817bb19275434707f1498e25d118bf; it lacks sessions,
jobs, and the browser UI and is **not** a demonstrated compatible image rollback.
The automated image rehearsal redeploys this same release's retained immutable
image. Schema-incompatible rollback requires a matching previous paired backup
and binary. Do not infer broader backward compatibility from that test.

Downgrading job aliases loses additional accepted keys. Downgrading sessions removes
ownership boundaries and invalidates browser sessions. Restore must preserve DB
and uploaded bytes together; never serve a partial restore. Runtime database,
filesystem, or provider outages still need operator intervention.

## Deferred external verification

No live Azure/LLM accuracy evaluation was performed, and no hosted HTTPS URL exists.
The evaluator supports opt-in billable checks on two fixed synthetic documents,
with field correctness, measured latency, failures, and model IDs. Configuration-only
mode sends no data. Even future success on this tiny corpus will not establish
production accuracy, compliance, or coverage/payment adjudication.
